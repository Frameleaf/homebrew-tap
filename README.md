# Frameleaf Homebrew tap

Homebrew cask for [Frameleaf Desktop](https://frameleaf.app/download/), the Mac app for Frameleaf, a self-hosted photo
and video library. Frameleaf is in beta.

```sh
brew install --cask frameleaf/tap/frameleaf
```

Frameleaf Desktop for Mac needs Apple Silicon. Source code: [Frameleaf/frameleaf-desktop](https://github.com/Frameleaf/frameleaf-desktop)
(AGPL-3.0). Questions: support@frameleaf.app.
